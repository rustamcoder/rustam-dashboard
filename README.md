# RUSTAM Personal Dashboard

Рабочий адаптивный прототип персональной системы продуктивности.

## Реализовано

- обзор с KPI, графиками, балансом жизни, целями и задачами;
- добавление и удаление целей;
- канбан задач и отметка выполнения;
- трекер привычек;
- статистика и интерактивные графики;
- Pomodoro-таймер и тихий звук дождя;
- заметки с автоматическим сохранением;
- бесплатный локальный помощник RUSTAM AI;
- светлая тема и выбор акцентного цвета;
- экспорт резервной копии в JSON;
- хранение всех данных в localStorage;
- мобильная адаптация.

## Запуск

Откройте `index.html` в современном браузере.

## Netlify

- Build command: оставить пустым
- Publish directory: `.`

Данные хранятся локально в браузере пользователя и не отправляются на сервер.
